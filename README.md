# Ket Qua Hoc Tap App

Desktop app quản lý kết quả học tập theo mô hình MVC.

## Công nghệ

- Python
- CustomTkinter + Tkinter Treeview
- SQLite
- Pandas, NumPy
- Matplotlib

## Chạy app

```powershell
pip install -r requirements.txt
python main.py
```

## Chạy test

```powershell
python -m unittest discover -s tests
```
